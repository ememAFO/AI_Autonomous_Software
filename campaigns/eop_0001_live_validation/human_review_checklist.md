# Human Review Checklist

## Launch material

- [ ] The selected public post accurately describes research, not a finished product.
- [ ] No unsupported savings, conversion or revenue claim is present.
- [ ] The form is provider-neutral and does not depend on Google Forms.
- [ ] Research and contact forms are separate.
- [ ] The public form does not request direct identifiers.
- [ ] The consent text is visible before submission.
- [ ] The active consent and question-set versions are recorded.
- [ ] A response token is generated.
- [ ] No public action has occurred yet.

## Evidence integrity

- [ ] Public-form responses remain hold-only.
- [ ] Direct interviews have human attestation.
- [ ] Concrete actions are completed, not hypothetical.
- [ ] Pilot measurements remain outside the validation evidence log.
- [ ] Negative and opposing evidence is retained.
- [ ] Self, collaborator, test and synthetic records are excluded.
- [ ] Duplicate detection is active.
- [ ] Free text has been checked for direct identifiers.

## Pilot design

- [ ] Baseline population and inclusion rules are defined.
- [ ] Intervention start is documented.
- [ ] Confounders are captured.
- [ ] Outcome counts include denominators.
- [ ] Effect magnitude is reported.
- [ ] Persistence will be checked.
- [ ] Customer-facing actions require contractor approval.
- [ ] Stop rules are documented.

## Decision

- [ ] APPROVE FOR LIMITED LAUNCH
- [ ] HOLD FOR CHANGES
- [ ] REJECT
